# Junior Match 🚀

Junior Match היא פלטפורמת השמה מודרנית המבוססת על מנגנון החלקה (Swipe) להתאמה מהירה, חכמה ומדויקת בין ג'וניורים בתחום הפיתוח והטכנולוגיה לבין מעסיקים.

## 🔗 קישורים לפרויקט
* **אתר באוויר (Live Demo):** [https://junior-match.vercel.app](https://junior-match.vercel.app)
* **מאגר קוד (GitHub):** [https://github.com/lielshvartz/junior-match](https://github.com/lielshvartz/junior-match)

---

## 🎯 הגדרת המוצר, ניתוח מתחרים והבידול

### הבעיה
ג'וניורים רבים נתקלים בחסמי כניסה גבוהים בשל סינון קורות חיים אוטומטי ודרישות ל"ניסיון קודם" בפלטפורמות הקיימות, בעוד שלמעסיקים אין דרך מהירה ונגישה להתרשם מפרויקטים מעשיים ויכולות קוד בפועל של מועמדים בתחילת דרכם.

### ⚔️ ניתוח מתחרים והשוואה מפורטת

| פלטפורמה | מה היא מציעה? | מה חסר בה? | הבידול של Junior Match |
| :--- | :--- | :--- | :--- |
| **LinkedIn** | רשת מקצועית עולמית ולוח משרות רחב | מוצפת במועמדים בכירים (Seniors); ג'וניורים נבלעים ואינם זוכים לחשיפה | פלטפורמה ייעודית ב-100% לג'וניורים ללא תחרות מול בעלי ניסיון |
| **AllJobs / דרושים** | לוחות משרות מסורתיים עם סינון טקסטואלי | דורשים שליחת קו"ח יבשים; אלגוריתם סינון אוטומטי לפי שנות ניסיון בלבד | התאמה אינטראקטיבית (Swipe) המבוססת על תיק עבודות ופרויקטים מעשיים |
| **קבוצות פייסבוק** | פרסום משרות מפה לאוזן ברשתות חברתיות | חוסר סדר, קשה לעקוב אחרי הגשות, אין מנגנון התאמה ישיר | מערכת ניהול מובנית: מעקב מועמדויות, התאמות הדדיות וצ'אט ישיר |

## 🔌 רשימת שירותים חיצוניים ואינטגרציות

| שירות / אינטגרציה | תפקיד במערכת |
| :--- | :--- |
| **Supabase Auth** | ניהול תהליך הרשמה, אימות והתחברות מאובטחת של משתמשים (ג'וניורים ומעסיקים) מבוסס JWT. |
| **Supabase Database (PostgreSQL)** | בסיס הנתונים הראשי של המערכת. כולל הגדרות אבטחה ברמת השורה (RLS) ומודל יחסים מלא. |
| **Vercel** | פלטפורמת אחסון ואינטגרציית CI/CD מול GitHub לצורך פריסה אוטומטית של ה-Frontend. |
